# Style Guide — Liftlog

- **Vibe:** a well-used gym notebook meets a scoreboard. Confident, high-contrast, fast. Not a generic SaaS dashboard.
- **Mobile-first:** design for a 390px-wide phone; it should still look intentional on desktop (centered column, max ~480px, or a two-column layout on wide screens).
- **Colors:** chalk white background, deep iron/charcoal text, ONE energetic accent (e.g. safety orange or plate-red) used only for primary actions and PRs. Error red must be distinct from the accent.
- **Type:** a condensed, athletic display face for headings and numbers (weights/reps should feel like a scoreboard); a highly readable sans for body.
- **Touch targets:** at least 44px tall. Primary button ("Start Workout", "Finish Workout") full-width.
- **Motion:** subtle and quick. A set row slides in when added; the PR trophy gets one small celebration. Respect reduced-motion.
- **Navigation:** bottom tab bar on mobile (Home · Log · History), highlights the current page.
- **Accessibility:** visible keyboard focus, labels on every input, contrast AA or better.
